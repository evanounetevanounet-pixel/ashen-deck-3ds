# Ashen Deck — prototype Nintendo 3DS

Jeu de cartes roguelike original pour Nintendo 3DS.

Fonctionnalités :
- menu principal
- deck de 12 cartes
- 5 types de cartes
- énergie
- PV et garde
- 2 ennemis normaux
- boss final
- combat au tour par tour
- écran de victoire/défaite
- consultation du deck

## Compilation

Installer devkitPro/devkitARM et libctru, puis depuis le dossier :

    make

Le fichier produit est :

    3ds_card_roguelike.3dsx

Copier ce fichier dans /3ds/ sur la carte SD et lancer Homebrew Launcher.

Ce projet est original et ne contient aucun asset ou contenu propriétaire de Slay the Spire.
